事業コンセプト

「日本一の営業マンが、日本の営業マンに贈る、商談前の武器」

オールインワン化粧水を起点に、年収1,000万円前後の「ちょっといけてる営業マン」を主軸ターゲットに据えた、1万円前後のミドル〜プレミアム男性スキンケアブランド。西日本某県・国内某地域レモンの成分ストーリーと、AI診断 × LINE CRM による「自分だけのオーダーメイド感」、そしてBtoB（福利厚生・営業部一括導入）を組み合わせた、デジタルマーケティング × 営業力のハイブリッド事業。

なぜ今、なぜこのチームか

市場側のタイミング

  • メンズコスメ市場：1,600億円（2024）→2,500億円（2030予測）、年成長6〜8%
  • 男性スキンケア習慣率：30代48%、40代42%（過去5年で2倍）
  • 営業マン高所得層（年収800万〜2,000万円）：約350万人、コスメ × 営業の空白地帯
  • D2C × LINE × AI診断が成熟、立ち上げコストが劇的に低下

チーム側の唯一無二性

  1. Y氏の業界トップ営業実績：商品より創業者ストーリーが効くカテゴリで圧倒的信頼資産
  2. 18名の母体組織：保険、AI、デジマの総合力。二刀流で着実に立ち上げ可能
  3. 西日本某県 × 国内某地域レモン：地理的アイデンティティと地元生産者との連携余地
  4. 3年役員報酬ゼロのコミット：本気度と意思決定スピードの両立

バリュエーション戦略

事業価値はチャーン率 × LTV で決まる。3年で次のいずれかの選択肢を取れる状態を作る：
- 上場準備：チャーン3%以下、LTV24万円超、年商15億円超
- M&A売却：化粧品大手・ヘルスケア企業によるロールアップ
- 自社継続成長：BtoB大型契約とライン拡張で安定収益化

属人化を排除し、創業者がいなくても回る仕組みを最初から組み込む。

営業マンが化粧品を買う理由

  1. 見た目が直接契約率に影響（第一印象・清潔感）
  2. 商談前の自己投資としての納得感（「これは浪費じゃなくて投資」）
  3. 時間がない → オールインワン需要
  4. 競合差別化のセルフブランディング
  5. ロールモデル（成功した営業）への憧れ

営業マン特有の購買パターン

  • ストーリーと実績に反応（自分も同じカテゴリだから理解できる）
  • 紹介に強い（人を動かすのが本業）
  • 一度信頼すれば長期顧客化
  • アンバサダー・リファラルとの親和性が極めて高い
  • 「会社経費・福利厚生で買える」を歓迎

  • 営業職比率高い企業ほど受容性高い

7. 法規制・参入障壁

  • 「人体に作用が緩和なもの」のみ表現可能
  • 効能効果は56カテゴリの範囲内
  • 表示・広告のNG：「シミが消える」「若返る」「医薬品的効能」

OEM選定

  • 国内主要OEM：日本コルマー、東色ピグメント、ピアス、コスメティックスローランド
  • 最小ロット：通常1,000〜3,000本／品目
  • 開発期間：6〜12ヶ月
  • 国産プレミアムレモン原料：地元生産者・農協との直契約余地

商標・知財

  • 「メラビアン」（仮）等のブランド名は早期商標登録
  • 「国産プレミアムレモン」「国内某地域レモン」の地理的表示活用

3. 社会的ジョブ：「ちゃんとしている営業マン」と思われたい／成功者と同じカテゴリに身を置く

→ 感情・社会的ジョブこそがブランドの本質。機能だけならドラッグストア品で十分。

  • 「あなたは『しっとり』タイプです」と断定的に
  • 商品提案は診断結果からの自然な帰結として
  • ロジックの透明性（「肌タイプA＋ライフスタイルB なので商品X」）

チャーン（解約）対策

解約率＝企業価値

解約率（チャーンレート）はLTVに直結し、企業価値（M&A・上場時のバリュエーション）を決定する。EBITDAでいくら出していても、チャーン高ければマルチプル2〜3倍で評価される。チーム全員が、解約率最重要KPIであることを理解すべき。

チャーン予測モデル（M9以降）

予測シグナル

  • 使用頻度の低下（写真送付の停止、診断未実施）
  • LINE反応率の低下（既読／クリック減少）
  • 購入間隔の長期化
  • カスタマーサポートへの問い合わせ内容
  • アンケート回答の変化

スコアリング

  • 高リスク：個別介入（LINE個別メッセージ、特別オファー）
  • 中リスク：自動配信のセグメント変更
  • 低リスク：通常運用

チャーン抑制施策

1. オーダーメイド感の積み増し

  • 月次の「あなた専用提案」
  • 季節別ケアの自動配信
  • AI診断結果のアップデート

2. ロイヤリティ特典

  • 6ヶ月継続：シルバー会員（特典：限定アイテム先行案内）
  • 12ヶ月継続：ゴールド会員（特典：顔診断AI無料、限定イベント招待）
  • 24ヶ月継続：プラチナ会員（特典：年1回特別ギフト、上位ライン優待）

3. アップセル戦略

  • 化粧水単品 → 化粧水＋乳液のセット
  • スターター → スタンダード → プレミアム
  • 「もう一段階上の自分」を訴求

4. 心理的な乗り換えコスト

  • 「自分専用」のオーダーメイド感が強いほど、他社に乗り換える心理コストが上がる
  • データが蓄積されているほど、捨て難い
  • LINEのやり取り履歴自体が「関係性の資産」

Part 7：BtoBで失敗する典型パターン

  3. 値引きで契約獲得：価格期待値が崩壊、長期で不利
  4. 担当者と関係が切れる：人事異動でゼロから関係構築
  5. 個別配送・包装で利益圧迫：オペレーション効率を見落とす
  6. コンプライアンス軽視：薬機法違反でブランド毀損
