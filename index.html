事業コンセプト

「日本一の営業マンが、日本の営業マンに贈る、商談前の武器」

オールインワン化粧水を起点に、年収1,000万円前後の「ちょっといけてる営業マン」を主軸ターゲットに据えた、1万円前後のミドル〜プレミアム男性スキンケアブランド。西日本某県・国内某地域レモンの成分ストーリーと、AI診断 × LINE CRM による「自分だけのオーダーメイド感」、そしてBtoB（福利厚生・営業部一括導入）を組み合わせた、デジタルマーケティング × 営業力のハイブリッド事業。

なぜ今、なぜこのチームか

市場側のタイミング

  • メンズコスメ市場：1,600億円（2024）→2,500億円（2030予測）、年成長6〜8%
  • 男性スキンケア習慣率：30代48%、40代42%（過去5年で2倍）
  • 営業マン高所得層（年収800万〜2,000万円）：約350万人、コスメ × 営業の空白地帯
  • D2C × LINE × AI診断が成熟、立ち上げコストが劇的に低下

チーム側の唯一無二性

  1. Y氏の業界トップ営業実績：商品より創業者ストーリーが効くカテゴリで圧倒的信頼資産
  2. 18名の母体組織：保険、AI、デジマの総合力。二刀流で着実に立ち上げ可能
  3. 西日本某県 × 国内某地域レモン：地理的アイデンティティと地元生産者との連携余地
  4. 3年役員報酬ゼロのコミット：本気度と意思決定スピードの両立

戦略要点

バリュエーション戦略

事業価値はチャーン率 × LTV で決まる。3年で次のいずれかの選択肢を取れる状態を作る：
- 上場準備：チャーン3%以下、LTV24万円超、年商15億円超
- M&A売却：化粧品大手・ヘルスケア企業によるロールアップ
- 自社継続成長：BtoB大型契約とライン拡張で安定収益化

属人化を排除し、創業者がいなくても回る仕組みを最初から組み込む。

営業マンが化粧品を買う理由

  1. 見た目が直接契約率に影響（第一印象・清潔感）
  2. 商談前の自己投資としての納得感（「これは浪費じゃなくて投資」）
  3. 時間がない → オールインワン需要
  4. 競合差別化のセルフブランディング
  5. ロールモデル（成功した営業）への憧れ

営業マン特有の購買パターン

  • ストーリーと実績に反応（自分も同じカテゴリだから理解できる）
  • 紹介に強い（人を動かすのが本業）
  • 一度信頼すれば長期顧客化
  • アンバサダー・リファラルとの親和性が極めて高い
  • 「会社経費・福利厚生で買える」を歓迎

  • 営業職比率高い企業ほど受容性高い

7. 法規制・参入障壁

  • 「人体に作用が緩和なもの」のみ表現可能

  • 表示・広告のNG：「シミが消える」「若返る」「医薬品的効能」

  • 国内主要OEM：日本コルマー、東色ピグメント、ピアス、コスメティックスローランド
  • 最小ロット：通常1,000〜3,000本／品目
  • 開発期間：6〜12ヶ月
  • 国産プレミアムレモン原料：地元生産者・農協との直契約余地

商標・知財

  • 「本ブランド（仮）」（仮）等のブランド名は早期商標登録
  • 「国産プレミアムレモン」「国内某地域レモン」の地理的表示活用

→ 感情・社会的ジョブこそがブランドの本質。機能だけならドラッグストア品で十分。

  • 「あなたは『しっとり』タイプです」と断定的に
  • 商品提案は診断結果からの自然な帰結として
  • ロジックの透明性（「肌タイプA＋ライフスタイルB なので商品X」）

チャーン（解約）対策

解約率＝企業価値

解約率（チャーンレート）はLTVに直結し、企業価値（M&A・上場時のバリュエーション）を決定する。EBITDAでいくら出していても、チャーン高ければマルチプル2〜3倍で評価される。チーム全員が、解約率最重要KPIであることを理解すべき。

チャーン予測モデル（M9以降）

予測シグナル

  • 使用頻度の低下（写真送付の停止、診断未実施）
  • LINE反応率の低下（既読／クリック減少）
  • 購入間隔の長期化
  • カスタマーサポートへの問い合わせ内容
  • アンケート回答の変化

スコアリング

  • 高リスク：個別介入（LINE個別メッセージ、特別オファー）
  • 中リスク：自動配信のセグメント変更
  • 低リスク：通常運用

チャーン抑制施策

1. オーダーメイド感の積み増し

  • 月次の「あなた専用提案」
  • 季節別ケアの自動配信
  • AI診断結果のアップデート

2. ロイヤリティ特典

  • 6ヶ月継続：シルバー会員（特典：限定アイテム先行案内）
  • 12ヶ月継続：ゴールド会員（特典：顔診断AI無料、限定イベント招待）
  • 24ヶ月継続：プラチナ会員（特典：年1回特別ギフト、上位ライン優待）

3. アップセル戦略

  • 化粧水単品 → 化粧水＋乳液のセット
  • スターター → スタンダード → プレミアム
  • 「もう一段階上の自分」を訴求

4. 心理的な乗り換えコスト

  • 「自分専用」のオーダーメイド感が強いほど、他社に乗り換える心理コストが上がる
  • データが蓄積されているほど、捨て難い
  • LINEのやり取り履歴自体が「関係性の資産」

由来：心理学者A. M.の「視覚優位の心理法則」（第一印象は55%が視覚情報で決まる）から。営業マンの第一印象＝収入というインサイトとブランドの存在意義を完全に一致させる。

強み
- 営業職に刺さる教養的バックグラウンド（多くの営業マンが知っている法則）
- 「商談前の身だしなみ」というブランドの提供価値と直結
- 海外展開時にも違和感がない響き
- 商標登録の取得余地あり（要確認）

懸念点と対応
- 「視覚優位の心理法則」自体には批判もある（55%は限定的状況のみ） → ブランド名としては「第一印象への投資」の象徴として活用、法則の正否を主張しない
- カタカナ表記とアルファベット表記の使い分け要設計

副案：創業者名ブランド（Joe Malone型）

例：Y & CO. / Y. SUMIDA / SR HOMME など

  • 強み：創業者の信頼資産を直結、Joe Malone・Tom Fordの系譜

Part 3：試供キャンペーン設計

目的

  • 営業先企業のリスク低減（「タダで試せる」）
  • 社員からのフィードバック収集による商品改良
  • 正式契約への移行率測定
  • BtoBとBtoCのファネル拡大（社員が個人購入する流れ）

パターン別キャンペーン

A. 営業部全員 × 3ヶ月無料配布

  • 対象：営業職比率の高い中堅企業
  • 費用：完全無料（マーケ投資として）
  • 引換条件：3ヶ月後に社員アンケート実施、契約検討
  • 目標：50%以上の社員が「継続したい」と回答

B. 役員ギフトプラン（上位層先行）

  • 対象：経営者・営業役員クラスへの個別ギフト
  • 費用：当社負担、特別パッケージ
  • 引換条件：3ヶ月後に正式提案ミーティング
  • 目標：紹介・社内推薦の獲得

C. 営業所単位パイロット

  • 対象：1営業所（10〜30名）
  • 費用：5,000円／人で3ヶ月（通常価格の半額相当）
  • 引換条件：3ヶ月後にKPI比較（契約率、顧客満足度）
  • 目標：データに基づく全社展開の根拠作り

配送パターン

  • デメリット：運用やや複雑

  • BtoC ファネルとの統合がスムーズ

Part 7：BtoB担当者の役割設計

初期（M1〜M6）：Y氏 + 住田（剣）が直接

  • Y氏個人ネットワークの活用が最大効率
  • 経営者・役員クラスはY氏が直接
  • 提案資料・運用設計は住田（剣）

中期（M7〜M12）：BtoB営業担当 1名採用

  • 業務委託 or 正社員
  • 営業出身、できれば保険・不動産業界経験
  • 経営者面談に同席し、徐々に独立対応
  • Y氏は経営者クラスへのキーパーソン対応に集中

拡張期（M13〜）：BtoB営業 2〜3名体制

  • 業界別・地域別の担当分け
  • マネージャー1名 + 営業2名
  • 顧客サクセス（既存顧客対応）担当を分離

Part 8：BtoBで失敗する典型パターン（再掲）

  1. 大口偏重：1社で売上の50%超 → 解約時の打撃大
  2. 個別カスタマイズ過剰：1社ごとに違う対応 → 運用破綻
  3. 値引き合戦：契約獲得のための値引き → 価格期待値崩壊
  4. 担当者依存：人事異動でゼロから関係構築
  5. コンプライアンス軽視：薬機法 × BtoB契約 → ダブルリスク
  6. 個人情報軽視：社員データの取扱いミス → 信頼喪失

→ 標準パッケージ + 少数オプション で運用を統一する。
